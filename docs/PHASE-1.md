# Этап 1 — визуальный фундамент

Цель: сделать интерфейс последовательным и плотным. Экран не должен выглядеть как
набор независимых карточек с одинаковым визуальным весом.

## Правила

- одна логическая группа — один контейнер;
- связанные факты показываются строками с общей сеткой «метка — значение»;
- важное действие получает розовый акцент; остальной интерфейс остаётся спокойным;
- каждая настройка содержит состояние, эффект, условие применения и путь отката;
- параметры прошивки, роутера и игровых драйверов не имитируются: для них создаётся
  отдельный экран ручных действий с проверкой текущего состояния.

## Следующий модуль

«Приватность и фон»: правила для диагностических данных и фоновых компонентов с
точной поддерживаемой версией Windows, сохранением исходного значения и откатом.
Службы добавляются поштучно — без общей кнопки, скрывающей фактические изменения.
